# 古着屋 Re:Loop（サンプルサイト）

GitHub Pages 公開用の、古着屋のウェブサイトサンプルです。店舗・商品・価格はすべて架空のものです。

## 構成
- `index.html` — トップページ（新入荷、カテゴリ、お店について、買取案内、アクセス）
- CSSはHTML内に埋め込み済みで、追加ファイルなしでそのまま表示できます

## GitHub Pages での公開手順
1. このフォルダの中身をリポジトリにアップロード
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
